# Менеджер задач (To-Do CLI) 📝

Консольное приложение на Java для управления списком задач.
Проект создан в рамках изучения языка Java и объектно-ориентированного программирования.

## ✨ Возможности
- Добавление новых задач (с проверкой на пустой ввод).
- Просмотр списка всех задач.
- Отметка задачи как выполненной.
- Удаление задачи по ID.
- **Автосохранение:** все задачи сохраняются в файл `tasks.csv` и загружаются при следующем запуске.

## 🛠️ Технологии
- **Java 17** (или 24)
- **Maven** (сборка проекта)
- **JUnit 5** (юнит-тесты)
- Хранение данных: CSV-файл

## 🚀 Как запустить

### Вариант 1: Через IntelliJ IDEA
Просто откройте проект и запустите метод `main` в классе `ru.chelgu.todo.Main`.

### Вариант 2: Через терминал (JAR-файл)
1. Соберите проект:
   ```bash
   mvn clean package
2. Запустите скомпилированный файл:
   ```bash
   java -jar target/todo-cli-1.0-SNAPSHOT.jar
   

### 🧪 Тестирование
В проекте написаны юнит-тесты для проверки бизнес-логики.
Чтобы запустить тесты, выполните:
   ```bash
   mvn test
   ```
